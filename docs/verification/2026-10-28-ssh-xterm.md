## 实现和安全边界

- 原生 Activity 保留原 SSH 命令解析、加密密码选择与严格 host pin；首次必须手动输入命令，不自动连接。
- WebView 虚拟 HTTPS origin 仅返回四个固定 assets，拒绝任意导航／其他资源及网络、file/content、子窗口；CSP 禁止 frame、object、connect、form，禁用远端链接激活。
- JSch 字节以 base64／JSON 引用传入 xterm Uint8Array。输出一片一回执，输入有界串行队列；尺寸回传设置 PTY。远端不成为 HTML／JavaScript，复制仅由用户点击，优先复制选择，未选择时复制有界终端文字。
- generation 隔离取消、迟到输出／输入／连接发布；主线程操作 View／窗口，worker 操作传输；销毁关闭连接、取消指纹等待及清理 WebView。连接边界重建 xterm，断开保存纯文字快照；半个 UTF8／OSC 不可跨连接泄漏。
